# 🤖 FAQ Chatbot using Python

## 📌 Project Description
This project is a simple AI-based FAQ Chatbot developed using Python.  
The chatbot answers user questions based on predefined FAQs using Natural Language Processing (NLP) techniques.

It uses:
- TF-IDF Vectorizer
- Cosine Similarity

to find the most relevant answer for the user's question.

---

## 🚀 Features
- Answers predefined questions
- Uses NLP techniques
- Handles unknown questions
- Simple and beginner-friendly
- Command-line interface

---

## 🛠️ Technologies Used
- Python
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity

---

## ▶️ How to Run

### 1. Install dependencies
```bash
pip install scikit-learn
```

### 2. Run the chatbot
```bash
python chatbot.py
```

---

## 💬 Example

### User Input:
```bash
What is AI?
```

### Bot Response:
```bash
AI means Artificial Intelligence.
```
